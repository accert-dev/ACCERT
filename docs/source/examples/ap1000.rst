AP1000
======

The AP1000 ACCERT example is in ``tutorial/accert/AP1000.son``. It represents
the overnight capital cost basis for a two-unit AP1000 plant, with total
electric output of 2234 MWe (2 x 1117 MWe).

The AP1000 and LPSR direct-cost basis follows Stewart W.R. and Shirvan K.,
"Capital cost estimation for advanced nuclear power plants," *Renewable and
Sustainable Energy Reviews*, Nov. 2021, 111880,
https://doi.org/10.1016/j.rser.2021.111880, and the TIMCAT reference
implementation at https://github.com/mit-crpg/TIMCAT.

.. code-block:: son

   accert{
       ref_model = "AP1000"
       use_gncoa = False
       target_dollar_year = 2025

       post_process { occ = true }

       power(Thermal){ value = 6800 unit = MW }
       power(Electric){ value = 2234 unit = MW }
   }

The AP1000 direct-account total is represented by account ``2`` and is
``6,673,722,963.402768`` in 2018 dollars. ACCERT prints account-review tables
in the configured target dollar year using CPI-U escalation. Set
``target_dollar_year`` in the ACCERT input to choose a supported CPI-U target
year. The timestamped account and cost-element CSV files retain their
reference-year cost columns; the separate ``*_post_*.csv`` summary records the
target year, escalated OCC totals, and ``$/kW`` values.

Running the Example
-------------------

Run from the ACCERT repository root:

.. code-block:: bash

   python src/Main.py -i tutorial/accert/AP1000.son

ACCERT writes timestamped CSV outputs such as ``ap1000_upd_acc_*.csv``,
``ap1000_upd_ce_*.csv``, and ``ap1000_post_*.csv`` in the current working
directory.

Using AP1000 Output in CRT or IAT
---------------------------------

To use the AP1000 ACCERT output as a CRT or IAT baseline, convert the
``ap1000_upd_acc_*.csv`` file with ``accert_output_to_crt_baseline`` and provide
the total 20s labor hours that should be assigned to the case:

.. code-block:: python

   from crt import accert_output_to_crt_baseline

   accert_output_to_crt_baseline(
       "ap1000_upd_acc_20260518_215922.csv",
       "ap1000_accert_for_crt_iat.csv",
       reactor_type="AP1000",
       total_20s_labor_hours=28_902_455.46,
   )

The converter keeps ACCERT direct-account costs and uses the selected CRT base
case, such as AP1000, SFR, or HTGR, to distribute factory cost, material cost,
labor cost, and labor-hour proportions. The converted CSV can be passed to CRT
with ``config["baseline_csv"]`` or to IAT with ``input_csv``. For the current
AP1000 CRT base case, use ``construction_duration_0 = 76`` months in the CRT
configuration.

The AP1000 bridge maps ACCERT accounts to CRT/IAT accounts as follows:
``211`` to ``211``, ``212`` to ``212``, ``213`` to ``213``, ``214`` to ``216``,
``215`` to ``214``, ``216`` to ``215``, ``217`` and ``218A`` through ``218V``
to ``214``, ``22`` to ``22``, ``23`` to ``232.1``, ``24`` to ``24``, ``25`` to
``26``, and ``26`` to ``233``.

The full workflow is available in:

.. code-block:: bash

   python tutorial/combined/accert_output_to_crt_iat_example.py
